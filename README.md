# Pocket Translator (PyQt5)

Kleines Lernprojekt zur Entwicklung einer Desktop-GUI mit PyQt5 und zur Anbindung externer APIs.

## Motivation
Ziel des Projekts war es, den Umgang mit GUI-Frameworks, Event-Handling und API-Integration in Python zu üben.

## Features
- Texteingabe und -ausgabe über GUI
- Sprachauswahl über Dropdowns
- Übersetzung via googletrans
- Reverse-Funktion zum Tauschen von Sprachen und Texten
- Reset-Funktion

## Tech Stack
- Python
- PyQt5
- googletrans

## Hinweis
Dieses Projekt dient ausschließlich zu Lern- und Demonstrationszwecken.
